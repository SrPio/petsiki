# PETSIKI

Plataforma para adoptar mascotas de forma sencilla, hecha con React.

> README provisional. La versión visual con banners y capturas llega en la Fase 3.

## Desarrollo local

Requiere Node 24 y [pnpm](https://pnpm.io) 10.

```bash
pnpm install
cp .env.example .env
pnpm dev
```

## Scripts

| Script           | Qué hace               |
| ---------------- | ---------------------- |
| `pnpm dev`       | Servidor de desarrollo |
| `pnpm build`     | Build de producción    |
| `pnpm test`      | Tests con Vitest       |
| `pnpm lint`      | Lint con oxlint        |
| `pnpm typecheck` | Chequeo de tipos       |
| `pnpm format`    | Formatea con Prettier  |
