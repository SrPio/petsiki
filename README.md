# PETSIKI

Plataforma para adoptar mascotas de forma sencilla, hecha con React.

> README provisional. La versión visual con banners y capturas llega en la Fase 3.

## Desarrollo local

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

| Script              | Qué hace               |
| ------------------- | ---------------------- |
| `npm run dev`       | Servidor de desarrollo |
| `npm run build`     | Build de producción    |
| `npm test`          | Tests con Vitest       |
| `npm run lint`      | Lint con oxlint        |
| `npm run typecheck` | Chequeo de tipos       |
| `npm run format`    | Formatea con Prettier  |
